# Preview e homologação

```bash
npm install
npm run dev
```

Acesse o endereço local informado pelo Vite. O workflow CI produz apenas testes e build: **nenhuma URL pública ou deploy Cloudflare**.

Homologar Chrome desktop, viewport 390px e 320px, teclado/foco, entrada de valores, lote=20, preços abaixo do custo, sem gastos externos. Não conectar domínio ou Cloudflare sem autorização separada.
